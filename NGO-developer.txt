HOW DATA IS PASSED
------------------
1. templateFlow reads template-2.pages and sections.*.variants
2. Each visible section is { type, variant, page, data: { [variant]: payload } }
3. getSectionComponent(category, type, variant) returns the TSX file from sectionRegistry
4. Component render: <Component data={payload} />
5. Page2 composers spread the same payload into child sections

Nav / footer hrefs live in Header.menu and Footer.footerColumns / footerLegalLinks
inside those variant objects in categoryContent.json.
